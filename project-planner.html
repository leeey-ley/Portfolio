Daily Planner

A small web app that lets users add, complete, and remove daily tasks.

Planner
My roleFrontend development
TimeOne week
ToolsHTML, CSS, JavaScript

The problem

Users needed a quick way to track simple tasks.

The project focused on the basic actions needed in a daily to-do list.

What I built

A small interactive task list.

  • Added tasks from an input field.
  • Marked tasks as completed.
  • Removed tasks when they were no longer needed.

What I learned

JavaScript can change a page after it loads.

This project helped me understand events, variables, functions, and changing HTML elements.
