Web App Case Study

Simple Dashboard

A beginner project that displays important business information in a clear layout.

Dashboard
My roleDesign and frontend
TimeThree weeks
ToolsHTML, CSS, JavaScript

The problem

Important information was difficult to scan.

The goal was to organize sales, customers, and recent activity on one responsive page.

What I built

A simple card-based layout.

  • Used CSS Grid to arrange dashboard cards.
  • Added a mobile layout with media queries.
  • Used JavaScript for a basic menu and filters.

What I learned

Good spacing makes data easier to understand.

This project helped me practice layout, reusable CSS classes, and responsive design.
