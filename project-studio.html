Website Case Study

Creative Studio

A simple studio website that introduces the team, services, and selected work.

Studio
My roleDesign and frontend
TimeTwo weeks
ToolsHTML and CSS

The problem

The studio needed a clear online introduction.

Visitors needed to understand the services, see examples of work, and find the contact details quickly.

What I built

A clean multi-section website.

  • Created a strong hero section and simple navigation.
  • Used reusable project and service cards.
  • Made the layout responsive for phones and tablets.

What I learned

A page should guide visitors in a clear order.

This project helped me practice visual hierarchy, spacing, and page structure.
